# VSCO 2 Community Edition solo violin bank v1

Thirty original CC0 WAVs (15 roots x soft/strong), pinned from sgossner/VSCO-2-CE
revision 440300901dfe9275fd84e0b7763af1f8443ae62e. Recordings by Sam Gossner and
Simon Dalzell; sample cutting by Elan Hickler/Soundemote. See LICENSE.txt,
provenance.json and preparation.json. All original bytes are retained.

This bank is an installed instrument dependency, not disposable build output.
The stable bank identity must not be silently replaced for existing project recall.
See docs/sampled_violin.md for preparation and playback behavior.
