# vsco2_cello_section_v1

Pinned VSCO 2 Community Edition CC0 originals. Source identity and SHA256 values are in `provenance.json`; `LICENSE.txt` accompanies the recordings. Baseline preparation is retained in `preparation.json`; runtime uses `sample_map_refined.inc`, `pitch_ratios.inc`, onset `blend_correlation.inc` and sustained `blend_envelopes.inc`. See `docs/sampled_flute_cello.md` for pitch convention, expression and limitations.

`preparation_refined.json` and `blend_envelopes.json` retain loop qualification and bounded energy-curve data from `tools/refine_flute_cello_samples.py`. The original stabilized maps are retained as reproducible preparation baselines.
