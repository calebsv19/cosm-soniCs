# Compact track headers and group overviews

Main Edit uses a consistent 200-pixel header column, 48-pixel base rows and 2-pixel lane gaps. Existing row zoom still controls timeline height, with a 36-pixel minimum. Names and disclosure arrows stay near the top; Mute, Solo, FX access, compact volume/pan fields and a live peak/clip meter occupy a compact second line. Minimum-height rows retain those controls. See [header mixer](header_mixer.md) for gestures, history and tighter timeline gutters. Controls share exact paint/hit geometry and retain stable track identities. Hierarchy indentation is capped at 30 pixels so deep nesting cannot consume the control area. Tall timeline rows leave controls compact.

The FX button selects the track or group and connects it to the existing effects/instrument inspector. The existing header name selection and rename behavior remains available. Group selection targets its bus effects, while child selection targets its own content and processors. Header width does not jump when groups appear.

Every visible group lane displays a derived overview of all descendant source regions, including sources hidden by a folded inner group. MIDI note strokes share a common group pitch range. Audio previews reuse the source waveform cache. Mixed groups use separate MIDI/audio bands. Real phrase boundaries, overlaps and gaps remain visible; source offsets and viewport trimming are honored. Group buses, ancestors and independent returns are not counted as source content. No merged region, copied notes or bounced asset is created. These are source-arrangement previews; they do not depict the processed bus output.

Click a group timeline lane to select the group. Double-click its overview to expand a collapsed group; the header arrow toggles either state. Folding selects the parent bus and remembers its primary child track/region by project, track and region lifetime. Reopening restores that primary selection when still valid and when the group remains selected. A hidden nested child resolves to its nearest visible ancestor. Deleted/replaced identities never redirect selection to a different region. This transient bookmark does not restore an entire multi-region selection or persist across project replacement.

Fold-only changes and their guarded history can run during playback. They assign view metadata without rebuilding DSP or sending audio commands. Parenting, order, sends and bus creation retain stopped editing. Recording, Test, export and active gestures still refuse conflicting operations. Common MCP routing tools inherit the same fold-only exception; exact-state and immutable receipt rules remain in force. Folding state is saved using the existing format-26 fields; no program or session version change is introduced.

Qualification includes compact geometry at minimum/normal/large heights, nested mixed previews and trim coordinates, native stable-control selection and FX ownership, live worker fold/history without added commands or stopped transport, byte-identical production audio before/after exploration, official SDK guards, navigation and the broad stable suite. Native Vulkan captures cover expanded, collapsed/playing, selected-bus and compact layouts. Physical mouse/trackpad and listening acceptance remain separate.
